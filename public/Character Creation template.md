# Character Creation Template Guide

This document provides guidance and a structured example for creating character prompts.

## Example Structure for Character Creation Prompt:

```
**[Character_Race] [Character_Class]**, [Character_Gender], [Age_Description], [Physical_Description_and_Key_Features], [Clothing_and_Armor_Description], [Weapon_or_Equipment_Description], **in an epic, dynamic position**, **split screen composition**, **left half: highly detailed close-up portrait of the face**, **right half: full body action shot of the character**, on a **clean white background**, intricate details, fantasy art, cinematic lighting --ar 16:9 [--no [Negative_Elements]] [--c [Chaos_Value]] [--p [Personalization_Style]]
```

### Explanation of Fields:

*   **[Character_Race]**: e.g., Human, Elf, Dwarf, Orc, Gnome, Goblin, Dragonborn.
*   **[Character_Class]**: e.g., Warrior, Mage, Rogue, Paladin, Archer, Bard, Cleric.
*   **[Character_Gender]**: e.g., Male, Female, Androgynous, Gender-neutral.
*   **[Age_Description]**: e.g., Young, Middle-aged, Ancient, Adolescent.
*   **[Physical_Description_and_Key_Features]**: Details about their body, hair, eyes, scars, unique markings, etc.
*   **[Clothing_and_Armor_Description]**: What they are wearing, style, material, colors.
*   **[Weapon_or_Equipment_Description]**: Any weapons, tools, or significant items they carry.
*   **"in an epic, dynamic position"**: Describes the character's pose and action.
*   **"split screen composition"**: Specifies the framing of the image.
*   **"left half: highly detailed close-up portrait of the face"**: Focus on facial details.
*   **"right half: full body action shot of the character"**: Showcases the character's full form and action.
*   **"on a clean white background"**: Specifies the background.
*   **"intricate details, fantasy art, cinematic lighting"**: Adds artistic style and lighting cues.
*   **"--ar 16:9"**: Sets the aspect ratio of the generated image.
*   **"[--no [Negative_Elements]]"**: Optional. Use to exclude unwanted elements (e.g., `--no blurry, deformed`).
*   **"[--c [Chaos_Value]]"**: Optional. Controls the randomness/variety (0-100).
*   **"[--p [Personalization_Style]]"**: Optional. A specific style or artist to emulate.

## UI Integration Note:

An info icon should be placed next to the "Character Creation" textbox label in the UI. Clicking this icon should display the content of this `docs/Character Creation Template.md` file in a pop-up or modal.
